Static LoRA — unconditioned correction

A learned rank-2 correction on the predictor's last block, applied identically to every episode and never updated. No optimizer, no context: nothing about the correction depends on what the controller observed. This is the control that asks whether conditioning buys anything — if a conditioned method barely beats it, the conditioning is decorative rather than load-bearing.

Reference: Predecessor project ~/HyperJEPA, the 'static' control arm @ 628dff7
